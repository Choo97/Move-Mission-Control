Mission Lookup

내 예약 조회

예약 번호와 예약 당시 입력한 연락처로 내 예약 상태, 견적, 수정 가능 여부를 확인합니다.

01 예약 번호 입력

예약 완료 화면 또는 안내 메시지에서 받은 번호를 입력합니다.

02 연락처 확인

예약 신청 때 입력한 연락처와 일치해야 예약을 볼 수 있습니다.

03 상세 화면 확인

진행 상태, 견적, 수정/취소 가능 여부를 확인합니다.

예약을 찾을 수 없습니다.

예약 번호를 모를 때

예약 번호를 잊었다면 예약 완료 화면, 이메일 안내, 문자 안내를 먼저 확인해 주세요. 그래도 찾기 어렵다면 관리자에게 예약자명과 연락처를 알려 확인을 요청할 수 있습니다.
