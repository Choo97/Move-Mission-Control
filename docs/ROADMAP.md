# 로드맵

현재는 고객·관리자 핵심 흐름과 배포 구조까지 구현한 포트폴리오 단계입니다. 다음 작업은 기능 수보다 실제 운영 안정성을 높이는 순서로 진행합니다.

## 현재 완료 범위

- React 고객 예약·조회·상세·FAQ 화면
- React 관리자 로그인, 예약, 알림, 리뷰, FAQ, 운영 설정 화면
- 예약 가능 시간, 견적, 고객 요청 승인, 알림 이력 REST API
- 관리자 인증, 조회 시도 제한, 개인정보 암호화·마스킹, 파일 검증
- Vercel 프론트엔드, Cloud Run 백엔드, Cloud SQL·Cloud Storage 배포 구성
- 백엔드 자동 테스트와 GitHub Actions 검증

## 다음 우선순위

1. 배포 환경에서 일반 예약과 비영리 도움 요청 전체 흐름 재검증
2. 서버 오류·응답 시간 모니터링과 운영 로그 확인 절차 추가
3. 데이터베이스 백업·복구 절차 문서화 및 테스트
4. 예약 사진 다운로드 권한 검증과 수명 제한 URL 적용
5. 관리자 역할 분리와 계정 관리 고도화

## 외부 서비스 연동

사업자 정보와 운영 비용이 준비되면 아래 기능을 검토합니다.

- SMS 실제 발송
- 카카오 알림톡
- 지도 기반 주소 검색과 거리 확인
- 결제가 필요한 운영 모델의 결제 기능

## 판단 기준

- 포트폴리오 단계에서는 구현된 기능이 배포 환경에서도 재현되는지를 먼저 확인합니다.
- 실사용 단계에서는 모니터링, 백업, 파일 보관처럼 장애와 데이터 손실을 줄이는 작업을 우선합니다.
- 비용이나 사업자 심사가 필요한 외부 연동은 핵심 흐름이 안정된 뒤 진행합니다.
